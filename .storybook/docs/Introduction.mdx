# Morphis — Komponen

Pustaka komponen **framework-agnostic** yang dibangun sekali sebagai
**Custom Elements** (Web Components native), lalu dipakai di framework apa pun,
HTML biasa, maupun Twig/Drupal.

## Mulai cepat

```bash
npm install
npm run dev         # docs UI + playground live  -> http://localhost:5173
npm run storybook   # Storybook                    -> http://localhost:6006
npm run build       # artefak ke dist/
```

## Konsumsi

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@morphis/components/dist/tokens.css">
<script type="module" src="https://cdn.jsdelivr.net/npm/@morphis/components/dist/morphis.js"></script>

<ui-button variant="primary">Simpan</ui-button>
```

- Pilih komponen di sidebar untuk melihat **preview, API, dan snippet**.
- Gunakan toolbar **Framework** di atas untuk mengganti bahasa snippet
  (Native HTML · Twig · React · Vue · Angular).

## Panduan

- **Theming** — token `--ui-*`, `::part()`, `::slotted()`.
- **Drupal** — cara menyalin `dist/` ke tema, `libraries.yml`, Twig.
- **Accessibility** — catatan a11y dan audit otomatis.
