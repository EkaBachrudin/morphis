# Integrasi Drupal

Morphis adalah HTML native + file JS per komponen + satu file token CSS.
**Tidak ada framework JavaScript yang perlu dipasang di Drupal** dan **tidak
perlu CDN** — cukup salin file yang dipakai dari paket npm ke tema.

## 1. Salin file ke tema

Setiap komponen punya paket sendiri (`@eka-morphis/button`, `@eka-morphis/card`, …).
Ambil dari `node_modules` (atau dari tarball) hanya yang dibutuhkan:

```
themes/custom/mytheme/libraries/morphis/
├── tokens.css        # dari @eka-morphis/tokens/dist/tokens.css
├── button.iife.js    # dari @eka-morphis/button/dist/button.iife.js
├── card.iife.js      # dari @eka-morphis/card/dist/card.iife.js
└── input.iife.js     # dari @eka-morphis/input/dist/input.iife.js
```

Gunakan varian **`*.iife.js`** (script klasik) agar tidak butuh
`<script type="module">`. Bila memakai bundler modern, gunakan `*.js` (ESM).

> Varian `*.iife.js` dan meta-bundle `morphis.js` sudah **self-contained**:
> runtime Lit ikut dibundel (sekitar 5–6 KB gzip) sehingga tetap tidak butuh
> `type="module"` maupun dependensi eksternal.

## 2. Definisikan Drupal library

`themes/custom/mytheme/mytheme.libraries.yml`:

```yaml
morphis:
  version: 0.1.0
  css:
    base:
      libraries/morphis/tokens.css: {}
  js:
    libraries/morphis/button.iife.js: {}
    libraries/morphis/card.iife.js: {}
    libraries/morphis/input.iife.js: {}
```

## 3. Attach library

Global (`mytheme.info.yml`):

```yaml
libraries:
  - mytheme/morphis
```

Atau per template Twig:

```twig
{{ attach_library('mytheme/morphis') }}
```

## 4. Tempel markup

Markup tiap komponen tersedia di `dist/<nama>.html` (atau
`packages/components/<nama>/src/<nama>.markup.html`):

```twig
{{ attach_library('mytheme/morphis') }}

<ui-button variant="{{ button_variant|default('primary') }}">
  <span slot="icon">{{ icon }}</span>
  {{ label }}
</ui-button>

<ui-card variant="outlined">
  <span slot="header">{{ title }}</span>
  {{ body }}
  <span slot="footer">{{ footer }}</span>
</ui-card>
```

> Jangan menulis utility Tailwind di markup Twig. Gunakan atribut publik
> komponen, token `--ui-*`, atau `::part()`.

## 5. Theming

```css
:root {
  --ui-color-primary: #e11d48;
}
```

## 6. Anti-FOUC

```css
:not(:defined) {
  visibility: hidden;
}
```

## Alternatif: meta-bundle

Bila ingin semua komponen sekaligus, salin `tokens.css` + `morphis.js` dari
`@eka-morphis/components` (atau varian IIFE per komponen) ke tema. Tidak ada CDN
publik karena paket di-host di GitHub Packages.

## Checklist

- [ ] `tokens.css` dimuat **sebelum** markup komponen.
- [ ] File `*.iife.js` dimuat sebagai script biasa (tanpa `type: module`).
- [ ] Override token ditulis setelah `tokens.css`.
- [ ] Cache dibersihkan setelah mengganti file (`drush cr`).
