# Morphis

Pustaka komponen **framework-agnostic** yang dibangun sekali sebagai **Custom
Elements** (Lit 3 + TypeScript), lalu dapat dipakai di framework apa pun, HTML
biasa, maupun Twig/Drupal.

- Enkapsulasi: Shadow DOM (`mode: 'open'`)
- Styling: Tailwind v4 (build-time, `@apply`) + design token `--ui-*`
- Theming: CSS custom property + `::part()` + `::slotted()`
- Runtime: **Lit 3** (±5–6 KB gzip, di-*share* lintas komponen; tetap custom element standar)
- Distribusi: paket npm per komponen (versioning independen) + markup HTML untuk Drupal

## Konsumsi

Paket diterbitkan ke **GitHub Packages**. Tambahkan `.npmrc` di project konsumen
(butuh PAT `read:packages`):

```
@eka-morphis:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=<PAT>
```

Per komponen (disarankan, versi independen):

```js
import '@eka-morphis/button';   // mendaftarkan <ui-button>
import '@eka-morphis/tokens/tokens.css';
```

Untuk HTML polos tanpa bundler (dari `node_modules`, karena tidak ada CDN publik):

```html
<link rel="stylesheet" href="node_modules/@eka-morphis/tokens/dist/tokens.css">
<script src="node_modules/@eka-morphis/button/dist/button.iife.js"></script>

<ui-button variant="primary">Simpan</ui-button>
```

## Panduan

- **Panduan/Paket Baru** — scaffold, build, dan rilis pertama paket komponen baru
- **Panduan/Publikasi** — alur Changesets: catat perubahan, naikkan versi, rilis per paket
- **Panduan/Theming** — token `--ui-*`, `::part()`, `::slotted()`
- **Panduan/Integrasi Drupal** — salin file per komponen ke tema, `libraries.yml`, Twig
- **Panduan/Framework** — React, Vue, Svelte, Angular, Solid, Qwik
- **Panduan/Accessibility** — catatan a11y dan audit otomatis

Komponen tersedia di grup **Components**; setiap halaman menampilkan preview
live, tabel API (Attributes/Events/Slots/CSS Parts/CSS Custom Properties), dan
snippet per-framework lewat toolbar **Framework**.
