# Paket baru

Panduan membuat **paket komponen baru** dari nol sampai rilis pertama. Setiap
komponen dipublikasikan sebagai paket npm tersendiri (mis. `@eka-morphis/badge`)
dengan versi independen. Untuk mekanik rilis umum (changeset, versi, CI), lihat
**Panduan/Publikasi**.

## Ringkasan

1. Scaffold paket dengan generator.
2. Link workspace.
3. Lengkapi komponen + anotasi.
4. Verifikasi lokal.
5. Rilis pertama.

## 1. Scaffold

```bash
npm run gen -- component badge
```

Generator membuat `packages/components/badge/`:

```
packages/components/badge/
├── package.json                 # @eka-morphis/badge, versi 0.1.0
├── tsconfig.json
└── src/
    ├── badge.ts                 # kelas <ui-badge> (Lit)
    ├── badge.css                # gaya (Tailwind lewat @apply)
    ├── badge.template.html      # template render (dikompilasi plugin `?html`)
    ├── badge.markup.html        # markup siap tempel (Twig/HTML)
    ├── env.d.ts                 # deklarasi tipe import `*.html?html`
    ├── badge.stories.ts         # contoh Storybook
    ├── badge.mdx                # halaman Docs komponen
    └── badge.test.ts            # tes Vitest
```

Paket memakai tag `ui-badge`.

> Nama harus kebab-case, mis. `badge` atau `data-table`. Paket yang sudah ada
> ditolak kecuali memakai `--force`.

## 2. Link workspace

```bash
npm install
```

npm workspaces menautkan `@eka-morphis/badge` ke `node_modules` agar bisa diimpor
dari paket lain dan dari Storybook.

## 3. Lengkapi komponen

Sunting `src/badge.template.html` (markup) dan `src/badge.ts` (logika). Komponen
dibuat dengan **Lit**: template ditulis di `badge.template.html` lalu diimpor
lewat suffix Vite `?html`, sementara state dideklarasikan lewat `@property`
(menjadi Atribut) / `@state` (internal). CEM (`litelement: true`) membaca
`@property` untuk mengisi **tabel Attributes**; anotasi JSDoc mengisi
slot/part/event/custom property.

```html
<!-- src/badge.template.html -->
<div class="ui-badge" part="root">
  <slot></slot>
</div>
```

```ts
import { MorphisElement, define, property, litStyles } from '@eka-morphis/core';
import style from './badge.css?inline';
import template from './badge.template.html?html';

/**
 * @element ui-badge
 *
 * @slot - Konten utama.
 * @csspart root - Elemen pembungkus.
 * @fires ui-click - Saat badge diklik.
 * @cssprop [--ui-color-primary=#2563eb] - Warna utama.
 */
export class UiBadge extends MorphisElement {
  static override styles = litStyles(style);

  /** Teks badge. */
  @property({ reflect: true }) label = '';

  override render() {
    return template(this);
  }
}

define('ui-badge', UiBadge);
```

> Isi template memakai sintaks Lit biasa (mis. `${ctx.label}`, `?hidden=${ctx.x}`,
> `@click=${...}`) dengan `ctx` = objek yang dioper dari `render()`. File
> diperlakukan sebagai **badan literal `html\`...\``**: helper `html`, `nothing`,
> dan `repeat` dari `@eka-morphis/core` tersedia tanpa import, dan nested template
> `html\`...\`` didukung (mis. untuk `repeat`). Backtick/backslash literal ditulis
> seperti di TypeScript (`` \` ``, `\\`). Karena berada di file terpisah, binding
> di dalamnya **tidak** di-type-check.

Aturan CSS: file komponen wajib diawali
`@reference "../../../../src/styles/base.css"`, dan utility Tailwind hanya lewat
`@apply` (tidak pernah di markup).

## 4. Verifikasi lokal

```bash
npm run build     # hasilkan dist/ tiap paket
npm test          # Vitest + @open-wc/testing-helpers
npm run storybook # HMR di :6006
```

Halaman komponen dan Docs muncul otomatis dari `badge.stories.ts` +
`badge.mdx`.

**Alias Storybook.** `npm run storybook` tidak menjalankan `build:components`,
jadi tambahkan alias di `.storybook/main.ts` agar dev me-resolve sumber
komponen (bukan `dist/` yang belum ada):

```ts
{ find: /^@eka-morphis\/badge$/, replacement: root('packages/components/badge/src/badge.ts') },
```

## 5. Rilis pertama

Generator memakai versi `0.1.0`, dan `changeset publish` menerbitkan versi yang
**belum ada di registry** — jadi rilis pertama bisa langsung terbit.

```bash
npm run typecheck && npm test && npm run build
npx changeset --minor @eka-morphis/badge -m "feat: komponen badge"   # atau: npm run changeset
npm run version-packages
npm run release
```

> Alternatif bila ingin lewat bump: set versi paket ke `0.0.0` lalu beri
> changeset `minor` → `0.1.0`.

## Checklist paket baru

- [ ] Changeset dibuat & rilis pertama dipublikasikan.
