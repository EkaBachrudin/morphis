# Accessibility

Setiap komponen dibangun dengan elemen native di dalam Shadow DOM (`<button>`,
`<label>` + `<input>`, `role="listbox"` + `role="option"`) sehingga semantik dan
perilaku keyboard diwarisi dari browser.

## Yang dijaga

- `ui-button` merender `<button type="button">`; `disabled` dipropagasi.
- `ui-input` membungkus `<input>` di dalam `<label>` (asosiasi label implisit).
- `ui-select` mengikuti pola ARIA *select-only combobox*: `aria-expanded`,
  `aria-activedescendant`, `aria-selected`, nama aksesibel dari label
  (`aria-labelledby`) atau `aria-label`, navigasi panah/Home/End/Enter/Escape/Tab.
- Slot kosong pada `ui-card` (header/footer) disembunyikan.

## Audit otomatis

Audit dijalankan dengan **axe-core** di dua tempat:

1. Addon **Accessibility** di Storybook (panel bawah tiap story).
2. Test e2e Playwright:

```bash
npm run test:e2e
```

Test gagal bila muncul violation axe pada halaman komponen.

## Melaporkan masalah

Tambahkan `aria-*` yang diperlukan lewat atribut pada elemen `<ui-*>`, atau
gunakan slot untuk memberi label/deskripsi tambahan.
