# Framework

Prinsipnya: **import sekali** agar custom element terdaftar, lalu pakai tag
HTML-nya. Karena `<ui-*>` adalah elemen native, **semua versi framework**
bekerja tanpa build khusus.

> **Catatan internal**: komponen dibangun dengan **Lit 3**, tetapi Lit hanya
> dipakai di dalam implementasi. Permukaan publik tetap custom element murni
> (atribut/property, `CustomEvent`, slot, `::part()`) — tidak ada API Lit yang
> bocor ke konsumen.

```ts
import '@morphis/button'; // daftarkan <ui-button>
```

## Kontrak umum

Terlepas dari framework-nya, semua komponen mengikuti kontrak yang sama:

| Interaksi | Mekanisme |
| --- | --- |
| Data masuk | atribut (string) atau property (objek/boolean) |
| Data keluar | `CustomEvent` dengan `bubbles: true, composed: true` |
| Komposisi | `<slot>` (default & bernama) |
| Gaya | Shadow DOM + `::part()` |
| Tema | CSS custom property `--ui-*` |

Event yang dipancarkan: `ui-click`, `ui-input`, `ui-change`. Listener menerima
`CustomEvent`, jadi nilainya dibaca dari `event.detail`.

## React

**React ≥ 19** sudah meneruskan property dan custom event secara deklaratif,
jadi cukup render tag-nya langsung:

```tsx
import '@morphis/button';
import '@morphis/tokens/tokens.css';
import { useRef } from 'react';

export function App() {
  const ref = useRef<HTMLElement>(null);
  return <ui-button ref={ref} variant="primary">Simpan</ui-button>;
}
```

**React 16.8–18** belum meneruskan property/custom event ke custom element,
jadi pakai wrapper `@morphis/react`:

```tsx
import { Button, Input, Card } from '@morphis/react';
import '@morphis/tokens/tokens.css';

<Button variant="primary" onUiClick={(e) => console.log(e.detail)}>Simpan</Button>
```

## Angular

Daftarkan elemen sekali di entry point, lalu izinkan custom element lewat
`CUSTOM_ELEMENTS_SCHEMA`:

```ts
// main.ts
import '@morphis/button';
import '@morphis/tokens/tokens.css';
```

```ts
import { NgModule, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';

@NgModule({ schemas: [CUSTOM_ELEMENTS_SCHEMA] })
export class AppModule {}
```

```html
<ui-button variant="primary" (ui-click)="onClick($event)">Simpan</ui-button>
```

## Vue 3

Beri tahu compiler bahwa tag `ui-*` adalah custom element (bukan komponen Vue),
lalu binding event memakai `@ui-*`:

```ts
// vite.config.ts
vue({
  template: {
    compilerOptions: { isCustomElement: (tag) => tag.startsWith('ui-') },
  },
});
```

```vue
<script setup lang="ts">
import '@morphis/button';
import '@morphis/input';
function onClick(event: CustomEvent) {
  console.log(event.detail);
}
</script>

<template>
  <ui-button variant="primary" @ui-click="onClick">Simpan</ui-button>
  <ui-input label="Email" type="email" />
</template>
```

## Svelte

```svelte
<script lang="ts">
  import '@morphis/button';
  function onClick(event: CustomEvent) {
    console.log(event.detail);
  }
</script>

<ui-button variant="primary" on:ui-click={onClick}>Simpan</ui-button>
```

## Solid / Qwik

```tsx
import '@morphis/button';
```

```tsx
// Solid
<ui-button variant="primary" on:ui-click={onClick}>Simpan</ui-button>

// Qwik
<ui-button variant="primary" onClick$={onClick}>Simpan</ui-button>
```

## Data kompleks

Atribut hanya menerima string. Untuk nilai kompleks (objek/array), set property
lewat `ref`:

```tsx
const ref = useRef<HTMLElement>(null);
useEffect(() => {
  if (ref.current) (ref.current as any).label = 'Email';
}, []);
```
